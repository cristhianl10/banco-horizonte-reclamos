# Hoja de ruta de implementación

## Iteración 1 — Fundaciones

- Crear solución .NET, API y aplicación Angular.
- Configurar repositorio, variables de entorno, CORS, Swagger y estructura por capas.
- Crear proyecto Supabase y esquema inicial.

## Iteración 2 — Identidad y catálogos

- Configurar Supabase Auth.
- Validar JWT y roles en .NET.
- Construir catálogos de categorías, prioridades, estados y SLA.

## Iteración 3 — Gestión de reclamos

- Registrar cliente y reclamo.
- Generar código, detectar duplicados y calcular prioridad/SLA.
- Crear bandeja, filtros y detalle.

## Iteración 4 — Atención y trazabilidad

- Asignaciones, reasignaciones y toma de casos.
- Estados, observaciones, adjuntos e historial de auditoría.

## Iteración 5 — Supervisión

- Tablero, alertas de SLA, métricas y gráficas.
- Pruebas de reglas críticas.

## Iteración 6 — Cierre de portafolio

- UI responsive, datos semilla y manejo de errores.
- Docker opcional, despliegue, README técnico y capturas.
